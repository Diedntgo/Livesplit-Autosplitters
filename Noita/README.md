# Noita Autosplitter
Livesplit Autosplitter for Noita

## Features
- Starts the timer when player spawns
- Splits:
  - On Game Complete screen (default)
  - On death
- Resets:
  - When starting new game (default)
  - On death

## Notes
- Resetting when starting new game also resets the timer when restarting the game

## Planned Updates
- Option to split when collecting an orb
- Option to split when entering NG+
